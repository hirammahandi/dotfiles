# Code Review Report Template

Use this template when synthesizing findings from all review agents into a final report.

```markdown
# Code Review Report: [PR #<number> | Local Changes]

## Executive Summary

- **Scope**: [Files/components reviewed]
- **Severity**: [quick | normal | strict]
- **Review Date**: [timestamp]
- **Reviewer**: Claude Code Multi-Agent Review Team
- **Agents Used**: [list of agents that participated]

## Strengths & Positive Changes

- [Well-implemented features]
- [Good practices observed]
- [Improvements over previous code]

## Issues Requiring Attention

### Critical Issues (Block Merge)

1. **[Confidence: XX]** [Category] — [file:line]
   - **Issue**: [Description]
   - **Impact**: [Security/Performance/Functionality impact]
   - **Recommendation**: [Specific fix]
   - **Cross-validated by**: [Agent(s) that corroborated]

### High Priority Issues (Should Fix)

[Same format as Critical]

### Medium Priority Issues (Suggested Improvements)

[Same format as Critical]

### Low Priority Issues (Optional Enhancements)

[Same format as Critical]

## Cross-Validation Results

### Corroborated Findings
- [Finding X confirmed by Agent A and Agent B]

### Challenged Findings (Resolved as False Positives)
- [Finding Y challenged by Agent C — reason: ...]

### Cross-Cutting Concerns
- [Finding from security also affects architecture because...]

## Refactoring Suggestions

- [Specific refactoring opportunities]
- [Design pattern applications]
- [Code simplification opportunities]

## Metrics

- **Complexity**: Average cyclomatic complexity [X]
- **Coverage**: [X]% statement | [X]% branch
- **Performance**: [Benchmark results if available]
- **Security**: [X] vulnerabilities found
- **Documentation**: [X]% API coverage

## Automated Check Results

- [ ] Lint: [Pass/Fail - X errors]

- [ ] Build: [Pass/Fail]

## Final Recommendation

**Decision**: [APPROVE | REQUEST CHANGES | COMMENT]

**Rationale**:
[Detailed explanation of decision based on findings]

**Blocking Issues**: [Count of Critical/High issues]
**Required Actions**: [Summary of must-fix items]
**Optional Improvements**: [Summary of suggested enhancements]

## Next Steps

1. [Action item 1]

3. [Action item 3]
```
